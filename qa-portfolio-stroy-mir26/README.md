# QA Portfolio: stroy-mir26.ru

Тестирование интернет-магазина стройматериалов stroy-mir26.ru (OpenCart).  
Ручное тестирование, API-тестирование (Postman), поиск дефектов валидации и безопасности.

## О проекте

Полный цикл тестирования: от чек-листа и тест-кейсов до прогона, фиксации дефектов и API-проверок.  
Проверены ключевые модули: шапка сайта, навигация, каталог, регистрация, авторизация, корзина, оформление заказа, калькуляторы, адаптивность, безопасность.

## Стек и инструменты

- Ручное тестирование: чек-листы, тест-кейсы, тест-раны, баг-репорты (Excel).
- API-тестирование: Postman (коллекция запросов).
- Техники тест-дизайна: граничные значения, негативные сценарии, техника состояний/переходов.

## Структура репозитория

- `manual/` — чек-листы, тест-кейсы, тест-раны, ручные баг-репорты.
- `api/` — Postman-коллекция (`stroy-mir26 API.postman_collection.json`) и API-баг-репорты.
- `screenshots/` — скриншоты дефектов и запросов.
- `README.md` — описание проекта.

## Как использовать

- Файлы в `manual/` удобно просматривать в Excel: там есть ID, шаги, ожидаемый результат, статус, приоритет, серьёзность.
- Коллекция в `api/` открывается в Postman: импортируй файл `stroy-mir26 API.postman_collection.json` через **Import**.
- Скриншоты помогают быстро понять суть дефектов.
